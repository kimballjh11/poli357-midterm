# POLI 357 Midterm Study Site

An interactive study site for the BYU POLI 357 (Middle East) midterm.

- `index.html`: course map, causal chains, comparison pairs, exam templates, and study schedule
- `m1.html` to `m6.html`: six teaching modules with model IDs, connections, and retrieval questions
- `style.css`, `module.js`: shared styles and behavior

Open `index.html` in a browser, or enable GitHub Pages (Settings, Pages, deploy from the `main` branch root).

Content labeled "outside context" draws on sources beyond Gelvin's *The Modern Middle East* and the course study guide.
